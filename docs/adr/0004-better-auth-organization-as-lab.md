# Better Auth Organization as Lab membership

Lab tenancy and desk membership use **Better Auth’s organization plugin**: a Lab is backed by an organization; membership roles use Better Auth’s names as ubiquitous language—**Owner**, **Admin**, **Member** (`owner` / `admin` / `member`). **Owner** is sole subscription payer and creates the Lab; **Admin** administers without paying; **Member** operates the desk. **Owner** and **Admin** may send **Invites** for Admin or Member only (Owner is never granted via Invite). Open registration is only for creating a new Lab as its Owner. A person may belong to multiple Labs; desk work requires an **active organization** on the session. The Better Auth **organization id** is the shared tenancy key on tenant-owned rows (Better Auth naming in the schema; domain noun remains **Lab**). Chosen over a custom membership table so invites, roles, and active organization stay aligned with Better Auth instead of a parallel vocabulary.
